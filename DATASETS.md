# Datasets

This file documents the datasets used for the paper experiments in
*From Jumps to Signatures: A Generative Method for Temporal Point Processes*.

The paper scope contains 9 datasets: 4 synthetic datasets and 5 real-world datasets.
Experiments are addressed by dataset name plus model config, for example
`poisson_three_marks/ddpm_test.yaml`.

## Synthetic Datasets

Synthetic datasets are generated or cached under `data/synthetic/`.
The cache files are derived artifacts and are regenerated by the corresponding data modules when absent.

| Experiment                | Process                    | Marks                        | Key settings                                            |
|---------------------------|----------------------------|------------------------------|---------------------------------------------------------|
| `poisson_three_marks`     | Homogeneous Poisson        | 3 categorical marks          | `base_intensity=1.0`, `time_max=12.0`, `data_size=2000` |
| `inh_poisson_three_marks` | Inhomogeneous Poisson      | 3 categorical marks          | `base_intensity=1.0`, `time_max=10.0`, `data_size=5000` |
| `hawkes`                  | Univariate Hawkes          | Trivial all-zero marks       | Single event stream                                     |
| `hawkes_3x3`              | 3-node multivariate Hawkes | Source-node categorical mark | `time_max=15.0`, `data_size=2000`                       |

For the Poisson marked datasets, the default mark probabilities are set in the dataset-local
experiment YAMLs. The inhomogeneous Poisson generator uses NumPy's global legacy RNG for
inter-arrival times, so full bitwise reproducibility requires controlling the global NumPy seed
before construction.

### EasyTPP Datasets

EasyTPP datasets are loaded through Hugging Face datasets as `load_dataset("easytpp/<name>")`
and cached under `data/easytpp/<dataset>/`. The loader uses the upstream `train`,
`validation`, and `test` splits.

The active real-world EasyTPP datasets in the paper scope are `earthquake`, `stackoverflow`,
`taobao`, and `taxi`.

### Yelp Mississauga

`yelp_mississauga` is loaded through the EDITPP-style loader from a processed `.pkl` file.
The file stores cumulative arrival times without an explicit anchor. The loader prepends a
0.0 anchor, shuffles with a fixed seed, splits 60/20/20 into train/validation/test, jitters
zero inter-arrivals for numerical safety, and supplies trivial all-zero marks.

## Data Tensor Contract

All paper data modules expose the same training contract:

- `inputs`: cumulative event times with shape `(N, L+1, 1)`.
- `inputs_len`: valid sequence lengths, including the anchor position.
- `marks`: mark ids with shape `(N, L+1)`, dtype `long`, 0-indexed.

For synthetic datasets, position 0 is an explicit anchor with mark 0. For EasyTPP datasets,
the first real event is normalized to time 0, so position 0 holds the first real event's mark.
The shape contract is the same in both cases.

## Configs

Dataset-specific values live under `test/paper_experiments/configs/<dataset>/experiment.yaml`.
Shared model configs live under `test/paper_experiments/configs/`.

For example:

```text
test/paper_experiments/configs/
|- sigtpp.yaml
|- ddpm.yaml
|- wgan.yaml
|- vae.yaml
|- deter.yaml
|- gamma.yaml
`- poisson_three_marks/
   `- experiment.yaml
```

`load_experiment_config(...)` merges the dataset-local `experiment.yaml` first and then the
selected shared model config.

## Access And Redistribution

The source code is MIT licensed. Dataset redistribution depends on the upstream dataset.

- Synthetic datasets are generated by this repository.
- EasyTPP datasets are downloaded from Hugging Face via the EasyTPP dataset namespace.
- EDITPP/Add-Thin derived files should be treated according to their upstream license and
  redistribution terms.

The public repository should not include private raw data, generated experiment outputs,
model checkpoints, or cached dataset binaries. Recreate or download datasets through the
documented loaders instead.

For implementation-level details, see
[`test/paper_experiments/data/README.md`](test/paper_experiments/data/README.md).
